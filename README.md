# Folder Mania

Windows app to customize folders with colors and overlay icons (Java 21, JavaFX, JNA).

Overlay icons can be PNG, JPG, GIF or **SVG** (SVGs are rasterized with [JSVG](https://github.com/weisj/jsvg)).

## Run from the IDE
Open the folder in IntelliJ IDEA (it imports the Gradle project), then run the Gradle task `run`.

## Build a Windows app
Run these on Windows (the bundled JavaFX jars are OS specific). The result includes its own Java runtime.

| Task | Output |
|------|--------|
| `gradlew packageApp` | `build/jpackage/output/Folder Mania/Folder Mania.exe` (portable folder, no install) |
| `gradlew packageInstaller` | `build/jpackage/output/Folder Mania-<version>.exe` (per-user installer with Start menu and desktop shortcut) |

`packageInstaller` needs the [WiX Toolset 3.x](https://wixtoolset.org) installed (`-PinstallerType=msi` builds an `.msi`).

## Context menu
Start the packaged app, then use **Tools > Add to folder context menu**. On Windows 11 the entry
appears under "Show more options".

## Notes
- `src/main/resources/app.ico` is the app icon (generated by `com.foldermania.tools.AppIconGenerator`).
- Before uninstalling, use **Tools > Clean up before uninstalling...** (or run the app with `--cleanup`)
  to remove the context menu entry and saved settings.
